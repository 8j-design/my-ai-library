## 本轮得到的核心认识

1. 意义相关不等于形状兼容；两个问题需要分别解决。
2. 可迁移的知识常落在一段边界、一个开口或一个部件角色中。
3. 简化需要检查被删信息由谁承接，不能按细节数量判断。
4. 留白可以形成第二图形、完成主体、提示缺失轮廓或组织图底，机制不同。
5. 动作和对象间关系也能成为意象，不必都变成名词图标。
6. 多个意义可以共享结构，也可以分属不同观看层级。
7. 文化来源、直接可见结构与官方寓意是不同层面的证据。
8. 理论要能解释实际部位，并接受改图与反例的检查。
