## 6. 草图筛选

先用“不成立 / 需改进 / 成立”三档判断，并为每项写一句证据。不要用总分掩盖核心问题。

| 维度 | 检查问题 | 证据/修改记录 |
|---|---|---|
| 品牌关联 | 每个主要意象是否能回到品牌事实？ |  |
| 结构自然 | 图形之间有真实共享关系吗？是否有生硬折点？ |  |
| 主要识别 | 第一眼主要看到什么？是否与目标冲突？ |  |
| 差异与记忆 | 与同类并排后，有什么独有特征？ |  |
| 尺寸与工艺 | 实际最小使用尺寸下，关键形与空隙是否保留？ |  |
| 系统一致 | 与字标、排版和主要媒介能否配合？ |  |

若核心形象持续误读、关键留白消失，或设计意义只能靠长篇说明维持，应先修改，暂缓定稿。

## 7. 验证顺序

1. 先看干净背景上的主标，检查整体轮廓与重心。
2. 根据项目要求检查单色、反白和彩色版本，明确哪些版本必须成立。
3. 数字端可先试 16、24、32、64 px 等尺寸，但这些只是检查样本；最终以实际触点为准。像素与毫米不可直接互换。
4. 印刷、刺绣、雕刻等按材料分别确认最小间隙和线宽，不用同一个数值代替全部工艺。
5. 让未听设计说明的人先描述所见，再说联想；记录原话，避免先提示隐藏元素。
6. 间隔一段时间后再问其记得的形态，与同类标志一起比较。少量访谈提供方向，不当作统计证明。
7. 最后放进真实主要场景，验证字标组合、背景干扰与延展规则。
