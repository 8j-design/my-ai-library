# 我的 GitHub 与 AI 资料库

这是你的个人学习起点：保存值得研究的 GitHub 项目，按任务找资料，记录真实使用结果，用 Git 保留修改历史。它是资料库和 Agent 的工作规则；AI 由你正在使用的客户端提供。没有内置模型、API 服务或后台自动执行。

## 先做一次 10 分钟练习

1. 在 Codex 中把这个文件夹作为项目打开。新建这个项目里的对话，让 AI 先读 `AGENTS.md` 和 `INDEX.md`。在其他聊天窗口，AI 不会自然知道本机这个文件夹。
2. 输入：**“我想学习 Git 存档。先查这个资料库，最多推荐一个项目，说明用途和限制，不安装工具。”**
3. AI 应找到马克的 `MarkTodo` 卡片。接着让它在 `notes/git-practice.md` 写下你理解的 Git 和 GitHub 区别。
4. 输入：**“检查刚才改了哪些文件，确认没有账号凭据，只把这篇练习笔记提交为一次 Git 存档。”**
5. 再输入：**“根据这次练习更新对应卡片的实际使用记录，并重建和检查目录。”**

验收标准：能找到卡片；能解释为什么选它；有一篇你的笔记；Git 历史新增一次提交。仅推荐到 MarkTodo，不代表它已经安装或运行。

## 只需记住四件事

- **收藏**：给 AI 一个仓库链接，生成待核查卡片。
- **查找**：描述你要做的事，让 AI 先查目录，再读最相关的一张卡。
- **验证**：做一个与你任务有关的小练习，记录输入、输出和结论。
- **存档**：检查修改，再提交；有远端仓库后再推送。

## 可以直接复制给 AI

**新增资料：**“把这个 GitHub 链接加入资料库。先读 README 和 License，填写具体用途、什么时候用、什么时候不用、证据和限制。没有运行过就写清楚。保存为待核查，不执行它的脚本。最后重建目录并检查。”

**使用资料：**“我要完成【具体任务】，期望得到【具体结果】。先读 AGENTS.md 和 INDEX.md，最多选一张相关卡片。说清楚为什么它比现有办法更合适。没有合适资料就直接做。”

**整理复盘：**“检查本次新增的卡片和笔记，合并重复内容；停用无价值项目，保留停用原因。只整理当前库，列出修改，重建目录，验证后做 Git 存档。”

## 想手动操作时

在这个目录运行，下列 `python` 指已有 Python 3.10 或更新版本；不需要第三方包。在 Codex 中可以直接让 AI 使用它已具备的 Python。系统没有 Python 时，仍可直接阅读、编辑 Markdown，不必先安装。

```text
python library.py search "Git 存档"
python library.py add https://github.com/作者/仓库 --title "项目名" --tags "关键词1 关键词2" --summary "它能帮我做什么"
python library.py index
python library.py check
```

新增链接按仓库根地址去重，GitHub 子页面会归入同一个仓库，原始地址保留在新卡片正文。重复添加不会覆盖原卡片。检索按标题、标签和一句话用途匹配，避免把“不适用”正文当成推荐理由；不是语义搜索，中文长句找不到时用短关键词。目录检查只检查记录和目录的一致性，不证明第三方项目好用。

这个版本面向单人、顺序编辑。不要让多个进程同时写同一资料库；它没有作者原版的并发事务和旧草稿保护。
