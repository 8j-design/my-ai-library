# 汉字创意结构：按问题选择机制

开放构思或诊断“没有新意”时读取。以下为本轮研究归纳的工具，不是必须执行的数量标准。

| 机制 | 实际改变 | 检验与失效条件 |
| --- | --- | --- |
| 局部替换 | 物象结构进入相容的笔画位置 | 粗细、方向、重量能否融入；图标粘贴不算共享结构 |
| 整体轮廓 | 多字共同服从一个物象或运动总形 | 字组是否为轮廓作出结构改变；外画动物内塞字可能只是组合 |
| 比例与重心 | 关键部件放大，邻部压缩、倾斜或回应 | 夸张是否由主题引起；避免无意义拉伸 |
| 跨字借笔 | 共用主笔、支撑、边界或空白 | 拿走一字是否会影响关系；掠过字下的长线不自动成立 |
| 正负形互构 | 黑形与空白同时形成信息 | 正形负形各自能否辨认，缩小会否闭塞 |
| 动作隐喻 | 笔画抓取、托举、让渡、冲开、靠拢 | 动作方向与受力关系是否可见，而非只在说明里 |
| 书写组织 | 聚放转停、轻重连断、跨字响应 | 强弱是否有节奏，避免每字同样夸张 |
| 古今转译 | 有依据的古字／文化对象产生构形规则 | 可追溯研究对象；不能把现代拼装称为真实字源 |
| 语义转化 | 旧结构断裂、剥离、生成或重组 | 变化过程或关键瞬间是否能看见；通用芯片／新芽未必切题 |
| 材料成义 | 翻折、展开、遮挡、侵蚀改变识别 | 材料行为是否构成主题；只换外皮仍是表面变化 |
| 动态与视角 | 时间、位置或投影决定另一层识别 | 两状态是否相互解释；静帧不能证明运动或工程落地 |

## 关系从哪里来

字形：笔画走向、部件归属、外轮廓、字内通道。含义：对象、动作、状态、关系。笔势：速度、压力、转折与呼应。整体：字间相互支撑、争让和疏密。观看：先看图还是先读字，第二层信息怎样出现。

选择其中有力的交点即可。例如“共生”可研究共同支撑和互让空间，不必固定做两个人；“新”可研究结构转化，不必固定使用科技节点。若用现代联想，明确它是创意构造。

## 检查草图

1. 标出共用的线／空白，以及它承担的两种功能；没有共用也可作为纯字形或排版方向，准确命名即可。
2. 暂时移除说明、背景和可分离装饰，看核心关系还剩什么。
3. 与原稿并排看，变化是否触及部件、字间组织或总形，而非仅换视觉外皮。
4. 按Logo或标题的阅读条件看原尺寸与缩略图；明确哪些识别依赖附注或停留。

## 研究与文化依据

- [国家图书馆·汉字的构成](https://memory.nlc.cn/topic/resource/62)：文字学边界；不能把所有汉字都当作象形。
- [陈楠访谈](https://www.ad.tsinghua.edu.cn/info/1205/28179.htm)：古文字研究转成网格构形系统；学习规则转译。
- [宁木NIMU·贪](https://www.xiaohongshu.com/explore/6a15e7ec0000000006036f4c)：本轮看首图与正文，抓取方向形成情绪表达。
- [灯笼合字](https://www.xiaohongshu.com/explore/69f83c22000000001a036257)：本轮看首图与正文，多字服从同一物象轮廓。
- [徐冰·英文方块字](https://www.xubing.com/en/work/details/198?type=year&year=1994)：本轮看教材与作品，改写文字组织与认知；属于英文方块字案例。
- [D&AD·殷琳琳访谈](https://www.dandad.org/work/annual-2021/behind-the-work/how-yin-linlin-drew-on-ancient-paper-crafting-techniques-to-create-a-book-with-dual-meaning)：读相关访谈，翻折、隐藏与显露；未逐页看完整书。
