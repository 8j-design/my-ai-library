# 影视创作

目标是推进用户当前作品，或解决当前创作问题。不要把项目名“导演”当作职责边界，也不要在一次局部修改中丢失原始任务。

## 按当前问题使用

整体审查看下方“能力、产物与证据”；写作与修改看“发展与修改”；表演、声画与后期看“制作与观看”；案例研究看“案例来源与验证边界”。按需执行，直接推进已授权产物。

## 创作中的判断

1. 从上下文整理意图、对象、交付、硬条件与资源；大改后复核。具体地方命题检查当地材料怎样改变作品，无命题时不擅自添加传播任务。
2. 选择适合材料的工作方式。剧情可从事件与关系发展；纪录可从研究和素材发现结构；诗性、实验与音乐影像需判断声画、感知和持续时间。允许交叉，不强行套同一模板。
3. 用实际场景或形式片段检验概念，随后用朗读、排练、粗预演、声音或剪辑暴露关键不确定性。不要只列抽象优点，也不要用精密分镜包装不成熟方向。
4. 制作反过来修改写作。根据人物与观看需要选择动作、空间、镜头、听觉视点、切点和时间，不按台词逐句配图。
5. 反馈保留准确范围，针对具体版本修改。不把“总靠揭秘”的批评扩写成禁反转或开场必须全解释。自然、清晰、有吸引力都需在产物中判断。
6. 在资源内形成完整可观看版本，实听实看并修改，再完成交付。环境做不到的工作说明具体缺口，不假装工具或人员已经具备。

## 记录证据

分别记录：读过的资料、执行的练习、通过的技术检查、用户／观众反馈及完整作品验证。格式通过、导出成功、单帧漂亮都不能证明艺术成立。

作品、素材及完整聊天留项目。用户授权归库时，只提炼可复用方法、来源、失败原因和必要验证，合并已有规范并重建检查目录。本入口是工作方法，不自带视频模型、收音设备、授权或外部服务。


## 能力、产物与证据

一个作品中各环节可迭代，不按部门机械交接。下表是检查缺口的地图，不是必须逐项填满的表单或艺术评分。

| 编号 | 环节 | 有用产物／验证 |
|---|---|---|
| C01 | 任务与范围 | 对象、意图、交付、硬条件、资源；改稿后对照实际段落 |
| C02 | 观察与研究 | 行为、事件、空间、不同视角；事实／讲述／推断分开，来源可追溯 |
| C03 | 概念与表达 | 少量实质不同方向及具体事件／形式片段，能比较观看差异 |
| C04 | 剧作与场景 | 人物、关系、事件、对白、时间与信息安排；连续场景与修改证据 |
| C05 | 表演与调度 | 可执行行动、空间与走位、排练／预演；动画也有表演 |
| C06 | 摄影与镜头 | 视点、景别、光线、运动、覆盖与连续；代表性镜头实测 |
| C07 | 美术与状态 | 人物、环境、道具依据；跨镜头的空间与状态一致性 |
| C08 | 声音与音乐 | 听觉视点、画外信息、对白／环境／效果／音乐分轨与实听 |
| C09 | 剪辑与时间 | 完整粗剪、围绕问题的版本比较及观看反馈 |
| C10 | 制片与资源 | 人员、预算、排期、素材权利、备份和必要替代 |
| C11 | 动画／AI／合成 | 代表性困难镜头；版本、输入、原输出、修订、成本与失败 |
| C12 | 后期与交付 | 完整片、必要工程与清单、输出检查、反馈修改及归档 |

证据记录包括任务、日期、输入与来源、产物、检查、实际结果、限制和下一问题。读过资料、做过练习、技术检查、作品反馈、完整作品验证分别写。资料卡既定状态不自动等于实践水平。

优先做能暴露当前关键问题的测试，而非所有环节同时扩资料。一个小流程跑通只证明该任务，不推定长片、剧集、所有片种或现场执行能力。

具体资源假设只对本项目当次有效；不能将“暂不实拍”等历史条件升级成永久偏好。


## 发展与修改

### 发现材料

研究能改变初始判断。观察具体人怎样工作、相处、犹豫和应付处境，保存不同视角；不能以主题词、象征和漂亮画面替代生活。没有做采访不编造口述。真实人物、历史和群体材料注明依据，纪录素材明确事实与重演边界。

### 从方向到作品

创新可来自题材、人物关系、处境、视点、事件发展、声画组织和制作语言。比较时说明根本差异，各给实际段落，不能只更换外观、谜底或结尾说明。

剧情可检查：人物为何这样做，他人如何回应，后果如何进入下一刻，关系如何受影响，观众可能关心什么。人物可矛盾、迟疑或不自知；不是每次行动都要口头解释。小传是辅助，行为和场景才是证据。

不同组织均可成立：因果推进、悬念追索、生活片段积累、多重讲述、主观／非线性组织、诗性与关联结构。结构选择取决于材料和意图，不靠更换结构名称制造创新。

纪录检查材料真实性、观点和编排；实验／诗性影像检查声音、画面、空间、持续时间如何作用。不要强制它们拥有单一主角和结尾解答。

### 写与改

场景写可表演、可感知的具体行为与声音；对白来自此人对此人的行动和关系，不能只交换信息或说主题。旁白和内心表达可用，需判断形式是否必要。

方向未成熟时先做一场或一个有代表性的片段，朗读、走位、粗预演再改。自然不等于无设计，清晰不等于解释所有信息，留白不等于作者没有依据。停顿也可以建立生活、关系和时间经验，不逐秒强加冲突。

用户否定时定位具体损失：偏题、人物不可信、事件刻意、关系扁平、重复观看机制、情感缺依据、形式无必要，或资源不能实现。提出对应改动，在同一问题上检验，不用更多方案冲淡失败。

先自由收集读者／观众反应，再追问；不提前给“正确主题”。区分有意多义、理解偏差、偏好和作品失效。保留反馈原意与版本关系，不将局部批评变成全局禁令。


## 制作与观看

### 表演、空间和镜头

先考虑人物彼此在做什么、观众跟谁经验，再设计走位、距离、遮挡、景别、光线与摄影运动。指令应可执行，不只要求“悲伤一点”。动画和生成角色也需要目光、动作、停顿和反应。

镜头不逐句翻译台词。覆盖为表演和剪辑提供有目的的选择；需要时画平面，核对轴线、视线、动作、道具状态与地理关系。打破连续规则可以是选择，需判断观看效果，不能只为炫技。

参考板不能证明角色和空间跨镜头一致。生成测试保存角色环境依据、版本、输入、原输出、挑选理由和修复，优先测代表性难镜头。

### 声音与剪辑

从发展期考虑听觉视点、画外信息、空间与静默。音乐不能代替人物、关系和事件；对白、环境、效果和音乐各有作用，避免无差别堆叠。

做带声音的完整预演或粗剪，再比较切点、反应、镜头持续时间与信息位置。必要时同素材只改变一个关键因素，先写预期，保存实际观看结果。连续版本改变后回看全片，而非只看局部。

助手未听到的音频不能凭波形宣称情绪有效。格式、峰值和时长属于技术证据；清晰度、空间、节奏和情绪仍需实际听看。

### 制作与交付

按表达需求选择真人、动画、AI、图形或混合方法，不以工具决定作品。确认必要资源、时间、费用、人员与素材来源；缺工作时说明替代及损失，不承诺不存在的能力。

保存原素材与工程、版本和备份。按实际交付端检查规格、完整播放、画面异常、声画关系、对白、字幕与片尾，提供必要工程和清单。权利处理针对实际使用材料，不在未有材料时堆泛化警告。

完整观看、反馈和修改是创作环节。导出成功不能证明好看；整部短作通过也不能推定大规模制作已经掌握。复盘有效选择、失败原因、资源影响和未解决问题，只把可复用部分写回资料库。


## 案例来源与验证边界

建立：2026-10-18。以下是本轮读取的创作者原始文字与官方资料；没有完成全片听看或逐镜分析。这里提供问题与试验方向，不存原文全文，也不复制其情节。

| 来源 | 已读内容与学习问题 | 可做的试验 |
|---|---|---|
| [Pixar《Piper》介绍](https://www.pixar.com/piper) | 官方介绍；具体需要怎样与环境连在一起 | 用不同材料写无旁白的行动场景，检查是否依赖解释 |
| [宫崎骏原始访谈](https://www.rogerebert.com/interviews/drawing-on-spirited-world) | 检索节选，整页受限；生活片刻与“间” | 保留／删去同一停顿，比较关系、注意与时间感 |

| [Sarah Polley 作者文章](https://blog.nfb.ca/blog/2012/08/29/stories-we-tell-a-post-by-sarah-polley/) | 全文；不同讲述能改变作品问题 | 分事实／记忆／推断，编排允许多种视角的材料 |
| [Alison Tatlock 问答](https://www.amc.com/blogs/better-call-saul-qa-allison-tatlock-on-finding-the-saul-goodman-in-gene--1055260) | 部分文字；人物进入新处境和视听准备 | 同一人物在两种处境作选择，检查人物而非外壳的变化 |
| [Walter Murch 访谈](https://www.filmsound.org/murch/interview-with-walter-murch.htm) | 剪辑示例文字，未核对片段；信息和吸收时间 | 同素材改变切点或过渡，比较实际观看 |
| [Randy Thom 作者文章](https://www.filmsound.org/articles/designing_for_sound.htm)与[Contact 访谈](https://www.filmsound.org/studiosound/pp_contact.html) | 文字；声音、视点与剧作互相影响 | 同画面不同听觉视点或声画进入时机，实听比较 |
| [Sean Baker BAFTA 讲座](https://www.bafta.org/media-centre/press-releases/bafta-screenwriters-lecture-series-sean-baker/) | 写作／制作／剪辑段落；素材与重排改变表达 | 计划、实际素材、粗剪三者对照，说明修改与资源妥协 |
| [John August 场景文章](https://johnaugust.com/2007/write-scene) | 场景必要性、人物与进入方式 | 以具体场景回答提问，结合其他方法，不机械套用 |

进一步研究按一个问题推进：原始资料 → 条件允许时实际听看片段 → 描述内容 → 分析形式与效果 → 用自己的材料试验 → 对照修改 → 记录限制。没有看片不补时间码，未听声音不写听觉细节。

### 本轮方法修订的证据

历史练习暴露出：概念替代事件、多个方向重复隐瞒后揭晓、人物与关系扁平、反馈被机械反向、修局部后偏离原题，以及文字包装早于实际验证。因此新增发展、视听制作与证据记录入口。

保留的通用做法：来源与推断分开，准确保存反馈，连续段落研究，视觉需求主次纠偏，具体作品与通用库分开。完整项目原件、用户聊天、失败剧本及未授权素材不随此摘要入库。

当前状态：方法建立，尚无使用本入口完成并经用户认可的整部原创影视作品。未来实践记录须包括版本、任务、产物、检查、实际反馈与限制；格式通过不得记为艺术验证。
