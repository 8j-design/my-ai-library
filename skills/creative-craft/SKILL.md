# 创意构思与设计落地

## 核心目的

把用户给的信息、要求与目标转化为有创意的想法，再按任务范围做成设计作品。创意需要同时满足：与目标有关、有具体而可辨识的表达、适合受众和媒介、能够制作。不要以手法数量、复杂隐喻或大段解释代替这些结果。

理解用户要的是构思、概念预览，还是完整作品。用户要求“制作、设计、完成作品”时，持续推进到实际视觉产物；只交文案、提示词或画面描述不算完成。用户只要分析或构思时，完成相应范围即可。

## 1. 建立简明需求

从用户消息、已有素材与会话提取以下信息，按项目规模简化，不要求用户填写整份表单：

- 对象：品牌、产品、服务、活动或主题；哪些信息是事实，哪些只是创意假设。
- 目标：想让受众知道、感受、记住或采取什么行动；主要目标优先于次要目标。
- 受众与场景：给谁看、在哪里看、观看时长、尺寸和媒介。
- 核心信息：最重要的一句话、可证实的卖点、必须出现的内容及禁止项。
- 偏好与资产：喜欢或不喜欢的表达、参考中想借的部分、已有 logo、包装、图片与字体。
- 交付：作品数量、用途、文件格式、是否需要可编辑版本；已有工期和成本限制。

关键问题仅在答案会改变设计方向或导致无法制作时询问，尽量一次合并。不要把缺少参考图当成无法开始的理由。低影响缺项使用合理默认并简短注明；价格、功效、品牌字样、尺寸等关键事实不编造。

只有主题也能启动：明确暂定受众、用途和目标，先产生创意方向或可修改的初稿。正式印刷尺寸、真实包装细节等不能靠假设完成的部分，提前标明需要落实。

把需求与验收标准压缩成几条可核对的陈述，例如“手机端缩略图能读到活动主题、日期和行动入口”。不要为简单任务输出冗长的过程报告。

## 2. 找到创意支点

先找受众处境、目标与对象特点之间的联系，再选择手法。支点可以是矛盾、日常洞察、使用行为、形状或材质特征、语言关系、文化语境、情绪或信息结构。

有参考素材时，按需要分析视觉元素、构图、色彩、叙事、文字和成立机制。说明借的是哪种关系或机制，以及如何迁移到当前目标；不要复制他人独特画面、文案和品牌资产。看不出原作手法时如实说明，不强行归类。

无参考素材时，直接从需求发散。跨品类联想是可选工具，不强制每个项目使用；本品类的真实洞察也可以产生新意。

创意阶段默认从现有信息出发，不为了找漂亮参考而无目的联网。用户要求检索、需要核实影响设计的事实或资产授权时，可以使用可用搜索工具；本机优先采用已配置的 agent-browser，遵守宿主工具要求。用户明确要求不联网时遵守，并将无法核实的事项标为未知。引用只附实际读取且支持论点的来源，不虚构证据。

## 3. 创意工具箱

保留以下 11 种手法作为可组合的方法，不要求逐项使用，也不限制采用其他合适的方法。

| 手法 | 用法 | 常见失效 |
|---|---|---|
| 意象提取 | 提取可迁移的关系、节奏、留白或感受 | 只抽出圆形、红色等泛化属性 |
| 古今类比 | 连接不同语境中的相似处境或需求 | 只换服装与装饰 |
| 借物喻今 | 用具体事物的属性和行为解释目标 | 相似关系太泛，与对象无关 |
| 符号转译 | 把可识别的结构转移到新语境 | 只换材质，没有新含义 |
| 视觉元素重构 | 改变比例、数量、位置或材质来突出一个关系 | 变量过多，重点丢失 |
| 正负形 | 让形与空隙共同承载信息 | 只能靠解释才能辨认 |
| 隐喻匹配 | 利用共同的行为、关系或体验建立联结 | 强行匹配外形，受众接不上 |
| 文字引文 | 调整熟悉文本的语境，使其产生新含义 | 来源不明、过于冷僻或套话 |
| 短句隐喻 | 用简短语言连接两个有张力的概念 | 为字数限制牺牲可理解性 |
| 谐音意象 | 让语音关系与可见画面共同表达主题 | 只有谐音，没有视觉和主题关联 |
| 图形重组 | 融合辨识特征，构成新的整体 | 只是并列拼贴，没有关系 |

可选组合：意象提取→借物喻今→图形重组；古今类比→符号转译→文字引文；正负形→短句隐喻；意象提取→视觉元素重构。组合时每一步应改变上一阶段的结果，不只列方法名称。

也可使用直接表达、排版、纪实、幽默、材质体验、信息设计或交互等路径。居中、大字、渐变、常见版式不是禁用项；当它们只是装饰且没有支持主题时，才需要改进。

本技能自包含，不依赖 craft_run.py、metaphor.py 或未附带的卡片库；不要声称运行过不存在的脚本。手法是工作工具，不构成独创性证明。

## 4. 形成并选择创意方向

开放任务通常先提出 3 个有实质差异的方向；用户指定数量、已有方向或任务很小时按实际调整。差异应来自核心表达、叙事、视觉机制或观看体验，而不只是换颜色和标题。

每个方向简明说明：

1. 概念名称与核心表达。
2. 对应用户目标及受众处境的依据；只给可核对的设计理由，不输出冗长内部推演。
3. 主视觉与信息关系：具体对象、动作或结构、位置、质感及文字层级。
4. 品牌、产品或主题如何参与表达，以及关键文案（任务需要时）。
5. 与其他方向的区别、主要理解风险、制作难点与解决办法。

按切题、辨识度、理解成本、对象契合度和制作可行性比较，给出推荐及取舍。评价依据可见方案特征，不捏造受众数据、独创性百分比或客观分数。

品牌或主题可以通过行为、体验、形态、语言和独有资产参与表达，不强迫产品拟人化或执行动作。替换成另一品牌或主题后几乎不需要改动，是需要检查的信号；仅移除 logo 后画面仍能理解，不自动判为失败。纯艺术、公益和文字作品按其目标评价。

对快扫传播，定义观众首先应理解的具体信息，保留明显线索。慢读、艺术或探索性作品可有层次，不强制三秒解释全部含义。缩略图和短时自查只是初步检查；没有真实受众测试，不声称“已证实三秒看懂”。

## 5. 从方向推进到作品

用户已选方向时沿该方向制作，不擅自换概念。用户授权自主决定或直接要求成品时，选择最符合需求的方向，简短说明后继续，不另设例行审批。用户明确要求先看方案再决定时，完成可评估的方案和必要预览，等选择后制作其余成品。

制作前记录轻量基线：所选方向、关键文字、必须保留的资产、规格和验收标准。不要把概念认可扩大为对所有细节的认可。明确要求变更时调整基线并说明涉及哪些作品。

根据设计选择媒介和现有工具：

- 摄影、插画或质感画面：使用宿主可用的图像生成或编辑工具；需要时读取对应技能。
- 几何图形、排版、图标、信息设计：优先使用 SVG、矢量或代码直接构造，不必强制 AI 生成底图。
- 需要准确字样、logo、价格、日期、二维码或尺寸标注时，采用可控图层排版并逐项核对。AI 生成文字是否可用以实际结果为准。
- 选择适合任务的导出流程；浏览器截图、生成图片或矢量文件各有用途，不强制绑定某一个浏览器或合成库。

先完成能检验核心表达的初稿，再精修。提示词清楚描述核心视觉关系、必须保留的元素和规格；提示词本身不算成品。包装概念图不自动等于可生产的刀模文件。

真实品牌资产以准确性为先。可以通过光影、透视、背景和材质融合真实包装，不禁止合理合成。AI 重绘可能改字或改变比例；不将失真资产当作正式包装。如用户要求设计新品牌资产，应按该任务创建，并说明是否经过必要核验。

仅使用实际可用工具，不虚构工具调用、图像额度或消费金额。有可靠计费信息且影响用户决策时提前说明，遵守宿主实际审批要求；用户已授权的常规制作不重复请求确认。

工具暂不可用时，继续完成可制作的图形、排版或可编辑构图；若核心视觉无法实现，交付实际已有产物，明确缺失和下一步，不把文字描述称为完成作品。没有制作工具时如实说明限制。

## 6. 控制迭代与不确定性

不要因为一个问题就推翻整套创意。先定位问题级别：

| 问题 | 修改范围 |
|---|---|
| 目标、受众或主张不对 | 回到需求，重新确定方向 |
| 概念相关但看不懂 | 调整视觉关系、关键线索或文案 |
| 排版、尺寸、光影、文字或资产错误 | 保留概念，修正执行 |
| 工具无法稳定实现核心画面 | 改制作方式；必要时比较可行替代方向 |

改变一个关键变量后检查结果，避免在失控底图上无限打补丁。相同失败连续两次且没有改善证据时，诊断原因并换制作方式；仍无法实现则说明限制和具体取舍。预算和修改轮次按用户约束执行，不自行设置付费额度。

修改记录可用“问题—改动—结果—剩余项”，按需要保存版本。保留用户选定方向及可回退的关键版本；不把不同概念的变化伪装成微调。达到验收标准后交付，不因个人审美无限返工。

## 7. 核验与交付

打开或渲染实际产物检查，工具返回“成功”不等于作品合格。至少核对主题表达、信息层级、字样、资产、比例、边缘裁切和输出尺寸；图像中的人物、产品、透视与细节按存在情况检查。

像素、边界框和碰撞检测可辅助发现遮挡，不能代替视觉核验与理解判断。无法查看产物时说明哪些检查未完成，不声称视觉通过。

按实际用途检查：

- 数字作品：目标像素、比例、文字可读性、安全区域及所需透明背景。
- 印刷作品：实际物理尺寸、出血、安全区、所需色彩配置和输出标准；有效精度由像素与最终物理尺寸共同决定，截图倍数不能证明印刷合格。
- 包装：区分视觉概念与生产稿；生产稿需真实刀模、尺寸及供应方规范。
- 系列作品：同一核心表达或设计系统，信息层级、资产和视觉规则一致；各张有实质变化，不要求每张一定使用不同喻体。

授权状态按实际字体文件、许可文本或用户提供的权利信息判断，不按字体名称或“系统字体/素材包”一概判定。不能核实的资产记录为待确认，不声称已授权。来源不明或带署名、版权标记的素材不自动去标；先选择可合法使用的来源或导出方式。

成品交付包含实际作品预览或文件、适用用途、必要的尺寸/格式，以及关键未完成项。需要可编辑版本时保留可编辑图层和必要资源；只有扁平图片时如实标明，不冒称源文件。链接和文件必须实际存在并能读取。

停止条件：作品满足约定核心目标与必需内容，达到对应媒介规格，实际视觉与文件核验完成，已知限制有说明。仅有创意描述、未查看的生成图或不符合媒介的文件不能标为最终完成。

## 对话中的执行方式

先给用户清楚的设计方向和可见进展，过程说明按任务复杂度控制。不要要求用户学习手法名或阅读全流程才可获得作品。新意应体现在具体设计决定上，并能说明与目标的关系；不承诺“全网唯一”“绝对原创”或未经测试的传播效果。

这个技能管理创意与设计执行，不自动授权发布、采购或向他人发送内容。用户的最新要求和宿主规则优先于本技能。
