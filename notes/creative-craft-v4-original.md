# 创意灵感构思与落地

手法驱动的创意工作流。**全程不联网**——创意来自素材与手法的推导，不来自抓来的图。

> v4.0.0 变更：新增「产品角色」「三秒可读」两条硬约束、品牌资产与字体授权规范、
> AI 出图落地规范、系列稿规范、交付纪律。这些来自一轮真实比稿中被用户逐条纠正的
> 教训，见文末《为什么加这些》。

## 基础规则（硬约束，不可绕过）

1. **不联网。** 不执行网页检索、爬虫、浏览器自动化访问。不尝试访问 ArtStation、站酷、花瓣、Pinterest 等站点获取素材。
2. **素材由用户提供。** 用户给什么就用什么；没给就纯主题发散，**不反过来要求补充素材、不提示去网上找**。
3. **11 种创意手法永久保留**，可自由组合：意象提取、古今类比、借物喻今、符号转译、视觉元素重构、正负形、隐喻匹配、文字引文、短句隐喻、谐音意象、图形重组。
4. **不输出站内检索链接。** 那些链接是给联网核验用的。既然不联网，就不输出看起来像证据的东西——没有核验过的东西不装成事实。
5. **用户认可的方案才是交付对象。** 可以推荐，但不要擅自切换到自己更喜欢的方案——两者不一致时先问一句。

## 四阶段工作流（严格按顺序，不可跳过）

### 阶段1 素材接收

接收用户手动筛选提供的：设计素材、作品描述、图片信息、关键词。逐份登记，记下用户标注的「你觉得它哪里好 / 想借什么」——这句话往往比素材本身更重要。

顺手确认三件事（后面会反复用到）：有没有**授权字体**、有没有**品牌资产**（logo / 产品包装高清图）、命题有没有**必须出现的元素**。

### 阶段2 素材拆解分析

每份素材拆六项，**顺序固定**：视觉元素 → 构图逻辑 → 色彩体系 → 创意手法 → 叙事内核 → 文字表达特点。

- 视觉元素只写名词，不写形容词
- 叙事内核必须含动词（不是「表达了美」，是「在硬撑」）
- 原素材用了什么手法看不出就写「看不出」，不要硬猜

没有素材则跳过本阶段，直接进阶段3。

### 阶段3 跨素材联想发散

按素材特征选手法（命中多个特征的优先），可自由组合。硬性要求：

- **提炼底层逻辑，不是照搬画面。** 每借一样东西都要写出「借的是它靠什么成立」。写不出这句，就是在抄外观。
- **至少有一条走跨品类。** 同品类之间只能得到搭配，得不到意外。
- 用组合链时，前一步的产出是后一步的输入，不要各做各的。

### 阶段4 创意方案产出

产出多套差异化方案。每套按固定顺序写，**顺序即思考顺序**：

1. **用了什么手法**（选了什么、为什么选）
2. **创意推导思路**（起点 → 转换 → 落点）—— 这一步最重要
3. **画面描述**（能直接交给设计师；写具体物、位置、材质、光）
4. **产品在画面里做什么**（**v4 新增，必填**）
5. **文字文案**（主标题 + 副标，语气要写明）
6. **自检**（含三秒可读与产品角色两问）

**先写推导再写画面。直接写画面等于跳过了思考。**

## 两条硬约束（v4 新增，最容易翻车的地方）

### ① 产品角色：产品必须在叙事里「做事」

每套方案必须写明：**产品在画面里正在执行什么动作**。

- ❌ 产品缺席（「画面里没有产品，空就是广告」）——**高危决定，默认不要用**
- ❌ 产品只是角标 / 贴片（产品不参与叙事）
- ✅ 产品是一个正在执行职能的**角色**：打扫的清洁工 / 运输的物流 / 同行的补给 / 开启的钥匙

**检查**：把产品从画面里拿掉，叙事还成立吗？成立就说明产品没参与叙事，只是贴了个标。

> 这轮真实教训：三张系列稿被连改三轮才对——从“画面里没有产品”→“产品出现在角落”→
> “产品在做事”。正确的一版是：房间里的药盒是打扫完的工具、城市里的货车正运着药片、
> 船上的药是出航补给。隐喻从「状态展示」升级为「产品行为叙事」。

### ② 三秒可读：隐喻必须留一个一眼可读的锚点

隐喻类创意必须有一个**不用解释就能看懂**的锚点，三选一：

- **喻体轮廓**：让房间整体呈胃形剪影（别只靠氛围暗示）
- **产品道具**：药盒/药片以道具身份出现在叙事里
- **场景线索**：一个能把观众接上品牌的具体物件

**检查**：不写注解，陌生人三秒内能看出「这是 X」吗？看不出就加锚点。

> 教训：概念图很美但观众读不出是胃、也接不上品牌——概念美但传播断裂。
> 广告是给三秒扫过的路人看的，不是给创作者自己看的。

## 11 种手法速查

| 手法 | 一句话 | 失效信号 |
|---|---|---|
| 意象提取 | 抽「留白」不抽「山」— 要可脱离原载体成立 | 抽出的是品类共性（圆形、红色） |
| 古今类比 | 共享**处境**才是类比，共享外形是 cosplay | 只换服装不换处境 |
| 借物喻今 | 属性是中间层，直接跳具象物只有表面相似 | 属性太泛（人生是旅程） |
| 符号转译 | 换载体不换结构 | 只换材质不换语境 |
| 视觉元素重构 | **只改一个变量**推到极端 | 同时改多个变量 |
| 正负形 | 负形承载第二语义 | 需要文字解释才看懂 |
| 隐喻匹配 | A 是 B，靠共享谓语成立 | 共享外形不共享行为 |
| 文字引文 | 换语境不换字 | 陈词（未来已来）或太冷僻 |
| 短句隐喻 | 两词硬碰撞，不加「像」 | 中文超 5 字 |
| 谐音意象 | 同音且**必须可画** | 只谐音不可画 |
| 图形重组 | 抽最辨识特征重新分配 | 并列不融合 = 拼贴 |

**富矿提示**：说明书体、法条体、公告体这类非文学文本做「文字引文」时反差最大——它们自带权威语气。

```bash
python craft_run.py --technique figure_ground   # 看完整算子
python craft_run.py --list                      # 11 种 + 4 条组合链
```

## 组合链

- **深迁移**：意象提取 → 借物喻今 → 图形重组（有素材但不想抄）
- **老树新枝**：古今类比 → 符号转译 → 文字引文（传统品类焕新）
- **一眼记**：正负形 → 短句隐喻（两色印刷、小尺寸受限时）
- **拆改**：意象提取 → 元素重构（已有明确素材要改造）

# 落地层（v4 新增）

创意定了之后真正的坑都在这里。

## 布局：AI 图当底图，矢量层重绘一切文字

**铁律：AI 出的图只当底图。所有文字、数字、标注线、logo 用 HTML/CSS/SVG 精确绘制。**

- AI 写的中文必糊、数字必乱（标注尺寸、编号全部不可信）
- 做法：底图（AI 生成质感）+ HTML 矢量层（可编辑、可改字）
- 截图：`playwright` + 本机浏览器（缺 headless shell 时用 `channel="msedge"`），
  元素级截图 `device_scale_factor=2`

## AI 出图六条硬经验

1. **水印是平台在输出时自动打的**，用 AI 修图没用（修完再生成还带）→ **用 PIL 裁掉边缘带**（如底部 72px）
2. **清晰度靠底图像素本身**：不要小图拉伸。直接出大尺寸（**1536×2048** 可用，是 1024×1536 的 2.25 倍像素）
3. **高清重绘会丢小物件细节**：放大重绘时必须逐条点名要保留的元素（「药盒必须有绿标、品名字、渐变条，不许简化或留白」），否则模型会把它们简化成色块
4. **双图输入（image1=海报, image2=真实包装）**可让 AI 按真实包装重绘画面里的产品，prompt 要强调「hand-painted / soft focus / 同尺寸同位置 / 不要像贴图」
5. **人物慎用**：AI 人体结构易崩；画面里**没起作用的人不如删掉**（删除比改正好改）
6. **出图前把「别人不会做的那个决定」写成 prompt 里最具体的一句**——决定越具体，概念图越能验证创意成不成立

## 版面合成：看不到图时的量化校验（新增）

合成阶段如果无法肉眼看成图，用像素度量替代：

1. **给底图做色域掩膜**，求关键元素的 bbox 与行列剖面（例：红＝喻体给料、饱和紫＝产品/主体）。
2. **坐标映射**：海报坐标 = 底图坐标 × (版面宽 / 底图宽)。底图与版面同为 3:4 时是纯缩放、无裁切，映射最准。
3. **碰撞检查**：把标题/文案/角色的矩形与 key 元素 bbox 对比。真实教训——标题压住了喻体、底部文案条埋掉了产品，肉眼看不见就会漏。
4. **内容偏好标明**：主体偏左/偏右由行列剖面读出，角色（IP/人物）应放到空的一侧。
5. **底部不要铺整条深色蒙版**——会把中下部的核心叙事（如「产品生出的意象」）一起埋掉。改用**局部文案底板**：`radial-gradient` 只糊在文字块正下方；主体若陷在暗背景里，再叠一层低透明度柔光把它托出来。实测：产品区仅被压暗 11，文字区压暗 53。

## 品牌资产：用真实的，但要融进画风

- ✅ 用素材包授权的 logo / 产品包装
- ❌ 不臆造品牌资产（不编 logo、不编包装上的字）
- ❌ 不把高清包装图**直接贴**进画面（会变成贴图，画风断裂）
- ✅ 正确做法：让 AI 按真实包装**重绘**画面里的产品，保持画风、同位置同大小

## 字体授权：系统字体默认不可商用

| 字体 | 版权方 | 商用 |
|---|---|---|
| 微软雅黑 / MSYH | 方正 | ❌ 系统 UI 授权，广告印刷需单独授权 |
| 中易楷体 / SimKai、宋体 | 北京中易 | ❌ 同上 |
| 苹方 / PingFang | 苹果·常州华文 | ❌ 同上 |
| 思源黑体 / 宋体 | Adobe·Google | ✅ SIL OFL 免费商用 |
| 素材包内授权字体 | 品牌方已授权 | ✅ 优先用这个 |

**做法**：先找素材包里的授权字体 zip，用 `@font-face` 引用本地文件，不用系统字体栈兜底。

## 系列稿规范

系列 = **同一方法、不同喻体**：

- 结构统一（版式、句式、产品出现方式）
- 喻体与动作有别（如：房间·晾衣 / 城市·骑行 / 海湾·划船）
- 每张的产品角色各不相同，但**都在做事**
- 系列自检：去掉品牌名，三张仍成立但互不重复；放在一起像一套而不是三张独立的画

## 交付纪律

1. **用户认可的才是交付对象**——推荐归推荐，别替用户做主切换方案
2. **产物核验以直读为准**——命令输出「成功」可能是幻觉（本轮真实踩到工具通道污染），
   关键产物必须逐个打开确认
3. **遗留项要写进交付说明**：AI 水印、乱字、印刷级重绘需求、商标检索建议

## 反思与迭代（每轮必做）

六问，任一不过关就**回到阶段3 换手法**（改画面没用，要换推导）：

1. 去掉品牌名，这个画面还成立吗？成立 = 通用模板
2. 有没有一个「别人不会这么做」的具体决定？没有 = 平庸
3. **不解释时，三秒内能看懂吗？** 看不懂 = 隐喻没有锚点
4. **产品在画面里正在做什么？** 答不出 = 产品只是角标
5. 画面描述能直接交给设计师吗？还是一堆形容词？
6. 如果只能保留一个元素，留下哪个？留不下来 = 没有重点

### 迭代方向（要变狠，不是变好看）

- **换手法**：这条走类比，换正负形会怎样？
- **推到更极端**：现在是「大一点」，推到「巨物」会怎样？
- **砍掉一个元素**：砍不掉说明每个都在承担意义，砍得掉说明有冗余
- **反着来**：情绪反过来（惆怅→得意）还剩什么？剩下的才是骨架

每改一版记一行四段式：**原以为 → 实际上 → 影响 → 下一步改什么**。只写「不好看」「再改改」的迭代等于没迭代。

## 平庸红线（命中即重做）

- 产品图居中 + 居中标题 + 渐变背景
- 「赋能 / 引领 / 新纪元 / 臻享」这类无信息量的词
- 抽象科技线条、光点、粒子作为唯一装饰
- 通用素材感的人物笑脸
- 三点式卖点水平排列配三个同样大小的图标
- 把 slogan 放大当主视觉
- 国潮 = 加云纹 + 红金（除此之外没有结构上的想法）
- 渐变 + 毛玻璃 + 大字（AI 生成图的默认长相）

## 诚实边界

- 手法库的**算子是 asserted**（我们写的推导程序，不是某权威教材转述）；示例为说明算子而构造，未在工作坊校验。
- 走「隐喻匹配 / 短句隐喻 / 借物喻今」时接驳 `metaphor.py`，那条路上的 150 张卡表是 verified（逐页提取自 CMU New Metaphors，CC BY-NC-SA，商用需自行授权）。
- **本 skill 不产出真实作品参考。** 需要看真实作品做到什么程度时，那是另一条路（联网检索），本 skill 不做。
- 若用户提供的素材是他人作品，只借底层逻辑，不复制独特构图、文案、logo 与品牌资产。
- 出图与高清重绘消耗图像额度，**调用前必须告知用户积分消耗**。

## 避坑

| 症状 | 原因 | 怎么办 |
|---|---|---|
| 产出像商业模板 | 跳过了阶段3，直接想画面 | 回到阶段3，强制走一条手法 |
| 「借了但说不清借了什么」 | 借的是外观 | 写出「它靠什么成立」，写不出就换手法 |
| 类比变成 cosplay | 共享外形不共享处境 | 先写现代对象的动词，再找古代同动词场景 |
| 谐音梗没有视觉 | 同音字不可画 | 不可画就放弃这条手法 |
| 想先定色板 | 用规格倒逼创意 | 方案选定后再填落地规格 |
| 想去网上找参考 | 旧习惯 | 本 skill 不联网；用主题发散或让用户提供素材 |
| 迭代越改越平 | 改的是视觉不是推导 | 换手法重推导，不是换滤镜 |
| 观众看不懂画面 | 隐喻缺锚点 | 加喻体轮廓 / 产品道具 / 场景线索 |
| 产品只在角落里 | 产品没参与叙事 | 给产品一个正在执行的职能 |
| 产品像贴上去的 | 直接贴了高清包装图 | 让 AI 按包装重绘，保持画风 |
| 局部擦除误伤邻近色 | 色阈值匹配到阴影里的相近色（如阴影黄流苏被当红擦掉） | 阈值收紧到目标主色（如纯红 r>190,g<85,b<85），或干脆抠出主体重组白画布再矢量重绘 |
| AI 底图返工越改越烂 | 在残次底图上层层打补丁 | 底图元素位置失控时，拆解重组（抠图+新画布+全矢量）比原地修补快 |
| 海报文字糊、数字乱 | 用了 AI 图里的字 | 矢量层重绘全部文字与标注 |
| 高清重绘后细节丢失 | 放大时模型简化了小物件 | prompt 逐条点名要保留的元素 |
| 水印去不掉 | 用 AI 修图 | 平台输出时打的，改用裁切 |
| 字体被质疑侵权 | 用了系统字体 | 换素材包授权字体或开源字体 |
| 交付了用户没要的方案 | 擅自切换到自己推荐的 | 用户认可的才是交付对象 |

## 为什么加这些（v4 的来源）

一套江中学院奖系列稿，被用户逐轮纠正出来的：

| 用户指出 | 暴露的问题 | v4 中的规则 |
|---|---|---|
| 「难道不能输出成果图吗」 | 只给文字，缺可视化 | 出图层 + 落地层 |
| 「不再联网，手法驱动」 | 取证承诺在不联网后失效 | 不输出检索链接（基础规则 4） |
| 「观众很难理解，也没体现产品」 | 隐喻缺锚点 + 产品缺席 | 三秒可读 + 产品角色 |
| 「难道不是按这个概念落地吗」 | 擅自切换方案 | 交付纪律 1 |
| 「检查字体版权」 | 用了系统字体（微软雅黑=方正） | 字体授权表 |
| 「把水印去掉」 | AI 水印修不掉 | 裁切法 |
| 「三张都加产品元素」 | 产品只是角标 | 产品角色：要在做事 |
| 「药盒按真实包装改，别贴图」 | 臆造包装 + 贴图断裂 | 品牌资产规范 |
| 「人物没作用且结构有问题」 | 冗余人物 + AI 人体崩 | AI 出图经验 5 |
| 「要高清」 | 底图像素不够 | 1536×2048 + 保细节 prompt |
| （工具输出污染事件） | 「成功」的 stdout 不可信 | 交付纪律 2 |

**总教训**：隐喻类创意最大的两个坑是**观众看不懂**和**产品不在场**；
落地最大的三个坑是**字体授权**、**AI 图当成品用**、**文字交给 AI 写**。
