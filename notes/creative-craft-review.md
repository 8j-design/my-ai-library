# creative-craft 的分析与改写记录

日期：2026-10-12。依据为用户提供的原文件和当前会话要求；以下评价属于设计及工程分析，不是完整项目实测结论。

## 用户目标

通过用户给出的信息、要求与目标，创造富有创意的想法，再产生具有创意的设计作品。用户不是只要手法讲解或提示词。

## 原版用途

v4 用 11 种手法拆解参考、发散海报创意，强调产品参与叙事、快速理解，以及 AI 底图和文字排版。其优点是避免只复制参考外观、只摆产品和只写抽象形容词。

## 问题与修订对应

| 原版问题 | 可能影响 | v5 调整 |
| --- | --- | --- |
| 手法优先，需求和传播目标不足 | 新颖但不解决用户问题 | 先提取目标、受众、核心信息与验收标准 |
| 产品必须执行动作 | 所有任务被套成拟人叙事 | 允许行为、形态、体验、语言和品牌资产参与表达 |
| 居中、大字、渐变等一律重做 | 为反套路牺牲清晰度 | 判断形式是否支持目标，不按外观禁用 |
| 三秒可读靠作者自评 | 高估受众理解 | 按媒介设置理解目标，区分自查与真实受众测试 |
| 任一检查失败就换手法 | 小错误引发概念反复重做 | 按需求、概念、表达、执行和工具问题分级修改 |
| 强制 AI 底图加矢量 | 简单设计也增加生成和合成成本 | 根据任务选择图像、矢量、排版或直接构造 |
| 重绘包装被视为正确方案 | 包装字样和比例可能失真 | 资产准确性优先，允许合理合成并核对 |
| 字体、水印与文字能力判断绝对化 | 误判权限和制作能力 | 依据真实文件、许可与输出效果判断 |
| 缺少版本、停止条件和交付规格 | 不断返工，成品不能使用 | 需求基线、分级迭代、媒介核验和完成标准 |
| 引用不存在的脚本和卡片库 | 执行路径中断 | 技能自包含，取消缺失依赖 |

## 修改过程

1. 阅读 v4 原文并检查目录，发现只有 SKILL.md。
2. 分析创意方法、规则冲突、技术落地与项目管理问题。
3. 按用户确认的核心目的改写 v5，保留 11 种手法作为工具箱。
4. 技能格式验证通过；保存 v4 原文备份，并更新 WorkBuddy 原文件。
5. 接入个人资料库的资料卡、检索入口、验证和使用记录流程。

## 尚未解决或验证

没有完整设计案例、真实受众理解测试、不同模型对比或印刷验收。对比优劣是分析判断，不是效果保证。该技能的许可来源和所用设计素材授权应在实际用途下确认；不承诺完全原创或传播效果。
