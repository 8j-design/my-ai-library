# 汉字创意同构：理论与可执行方法

[总入口](README.md) · [工作表](workflow.md) · [检验记录](validation.md)

## 先区分正在做什么

| 层次 | 改变对象 | 不宜混称的情况 |
| --- | --- | --- |
| 排版 | 字的大小、方向、位置、层级和字间关系 | 有效排版可以不改字形 |
| 字形重构 | 笔画、部件、比例、连接和外轮廓 | 几何变形未必产生语义意象 |
| 意象化 | 形态唤起事物、动作、情绪、文化联想 | 不必都对应一个实物图标 |
| 字图同构 | 文字与图形共用实际结构 | 插画与字叠放只证明组合，不证明共享笔画 |
| 系统或字库设计 | 可扩展字形规则及应用一致性 | 一组艺术标题不等于完整字库 |

同构可发生在局部笔画、单字、多字整体或时间变化中。它有不同程度，不必把每个字都图形化；应具体指出哪一部分同时承担了两种功能。

## 工作模型：形、义、势、境与观看过程

- **形**：骨架、部件归属、伸展方向、外轮廓和内部空白。
- **义**：词语指向的事物、动作、状态、关系；从名词扩展到动词。
- **势**：速度、压力、轻重、连断、倾斜和跨字响应；规则可用于书写，也可用于几何构成。
- **境**：字与字、字与环境共同形成的整体场面，不是所有字各加一个装饰。
- **观看过程**：先认图还是先读字；停留、翻折、视角和运动是否使第二层信息出现。

这是本轮研究形成的设计工作模型，并非传统文字学的固定分类。国家图书馆对形音义与六书的介绍提供文字学边界；不是所有汉字都由象形生成，现代“共像两个人”也不能当成字源。[来源](https://memory.nlc.cn/topic/resource/62)

## 11种方法：操作、理由与失效条件

| 方法 | 可见操作 | 何时有用 | 常见失效 |
| --- | --- | --- | --- |
| 局部替换 | 在相容的笔画位置引入物的结构 | 保留读字速度并设置发现点 | 图标粘上去，粗细方向与字脱节 |
| 整体轮廓 | 多字共同服从一个物象或运动轮廓 | 节庆、展览、主视觉 | 外面另画动物，里面仍是无关排字 |
| 比例与重心 | 放大关键部件，压缩邻部回应 | 突出命题的矛盾或力量 | 无主题的随机拉伸 |
| 跨字借笔 | 邻字共用主笔、支撑或边界 | 合作、共生、汇聚等关系 | 长线从字下掠过，字结构毫无变化 |
| 正负形互构 | 字内外空白形成第二形象 | 单色图形、双重阅读 | 空白缩小消失或只能靠解释猜出 |
| 动作隐喻 | 让部件抓取、让渡、托举或冲开 | 抽象情绪、状态、关系 | 说明写动作，画面只有静态小图标 |
| 书写组织 | 安排聚放转停、轻重连断与响应 | 需要书写张力的题目 | 每字同样夸张，缺少视觉停顿 |
| 古今转译 | 从有依据的古字或对象提取构成规则 | 文博、文化系列 | 把古纹样贴上去，或伪造字源 |
| 语义转化 | 旧结构断开并生成另一结构 | 更新、变化、成长等命题 | 只加芽、芯片、节点，变化不发生 |
| 材料成义 | 翻折、遮挡、展开、侵蚀改变识别 | 书籍、实体与静态关键瞬间 | 只换金属、玻璃外皮 |
| 动态与视角 | 不同时间或位置显出相关状态 | 动画、装置、观看体验 | 旋转特效代替语义，单帧冒称已落地 |

上述分类可交叉组合；方法数、复杂度和长提示词均不构成原创性证明。案例依据见 [平台资料](sources-social.md) 与 [原始资料](sources-primary.md)。

## 共享结构怎样检查

1. 指出具体线条、边界或空白：它在字里承担什么，在物象里承担什么？
2. 去掉可分离的装饰、颜色和解释后，核心联系是否仍可见？这是诊断手段，不是要求所有作品必须单色。
3. 把主题换成另一词句，若几乎无需改图，应检查关联是否过于泛化；不据此机械淘汰通用版式。
4. 原尺寸、缩略图分别看文字与图形。复杂艺术标题可允许延迟阅读；活动信息仍应有可靠识别路径。
5. 同构不足时可以承认是“图文融合/部分同构”。好看的组合无需冒称完全同构。

## 中国味道从哪里来

可以来自文字构成、书写节奏、留白、印章的层级、剪纸或翻折的组织方式、具体生肖形态及节庆语义。红金和毛笔是羊年题的有效选择，不是“中国味道”的充分条件。陈楠把古文字研究转成网格规则、徐冰改写阅读组织、殷琳琳以翻折呈现字与时间，分别提供了结构、认知和材料的路径；不能仅收集表面符号。[来源与阅读范围](sources-primary.md)
