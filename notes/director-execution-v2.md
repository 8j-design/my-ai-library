# 导演需求适配工作表 v2

日期：2026-10-15。状态：待实际项目验证。依据本次目的性审查补充，供后续任务直接执行；不代表模型或制作能力已升级。

## 使用顺序

先读本表和 director-project-continuity.md，再读与任务有关的原始材料。任务简单时合并交付，不机械要求用户填写表格。用户已确定的选择继续沿用。缺少资料时先自行检索，只有作者意图、资源权限或关键取舍无法查得时才询问。

### 1. 一页需求简报

| 项目 | 必须记录的内容 |
| --- | --- |
| 主目标 / 次目标 | 完成什么；发生冲突时优先哪一个 |
| 观众与观看场景 | 已知信息；暂定假设；来源。没有证据不编人口画像 |
| 观看结果 | 希望记住、感到、理解或做到什么；是否需要行动依任务决定 |
| 内容依据 | 对象事实、来源、可用素材；明确观察、解释与虚构 |
| 制作边界 | 媒介、资源、时长、规格、期限；未知项是否阻断当前步骤 |
| 本轮交付 | 提案、关键帧、动态分镜、镜头小样或成片，注明完成层级 |

### 2. 方案到执行的对应表

每案填写至少一条完整对应，比较方案时必须同时展示风险，不能只写优点。

| 目标 | 观众得到什么 | 具体事件/信息 | 视听选择及作用 | 核验方式 | 失败后的调整 |
| --- | --- | --- | --- | --- | --- |
| 待填 | 待填 | 待填，避免仅写主题词 | 待填，说明为什么用 | 待填，区分自查与实际观看 | 优先保留核心作用调整实现方法 |

地方/品牌任务做替换检查：换掉名称与标志，事件和观众认识是否仍完全一样？若是，补对象的具体作用。作者和实验作品不强套地方宣传标准。

### 3. 分镜执行最小字段

镜号与时长；本镜作用；开场/结束画面；景别、机位与空间方向；人物动作及视线；相机运动起止、路径、节奏和动机；构图及注意力；色彩、光线和材质；对白、环境声、音乐及声画关系；衔接依据；必须准确的对象特征；素材来源和制作方法；验收条件与替代方案。

焦距等数值只在已确定空间与工具时填写，不凭空制造精确感。二维明确图层、关键姿态和时间；三维明确相机/动作；AI明确参考、连续性和条次；实拍明确调度、收音和连续性。各项按需要取用。

### 4. 阶段交付与退回条件

| 阶段 | 实际交付 | 检查不通过时 |
| --- | --- | --- |
| 提案 | 简报、事件结构、目标对应、事实与虚构边界 | 改主线，不用结尾口号补主体缺口 |
| 风格预览 | 可查看的关键画面，标参考或自制 | 改构图/辨识/风格；不据静帧断言运动成立 |
| 动态分镜 | 带临时声音的可播放时间线 | 改信息顺序、时长与声画，记录具体时间点 |
| 关键镜头测试 | 实际输出与期望动作对照 | 换实现方案，必要时说明核心取舍 |
| 粗剪 | 连贯样片、实际反馈或“未测” | 区分目标错误、理解错误与制作问题后修改 |
| 交付 | 成片、规格检查、素材授权记录、复盘 | 保留待修项，不称全部通过 |

阶段不构成反复索要许可的关卡；在已授权范围内自主推进。不得把文字描述称作视频预览。

### 5. 版本与反馈

每次修改记录：触发问题 → 原判断 → 修改 → 影响的剧本/镜头/声音 → 实际验证 → 未解决项。已选方向和事实结论有变化时明确说明，旧版保留。

观看测试先让观众自由复述，再问记住什么、哪里不明白、在哪一刻失去兴趣；不先解释标准答案。记录原反馈和助手解释两列。没有反馈就写未测；不虚构分数、观众或传播效果。

## 兴光项目应用：目前可填的简报

- 主目标：按用户明确要求，使作品对南海子及其所属地域的文化传播发挥作用；赛事主题为“我眼中的南海子”。
- 次目标：具有作者表达和新鲜的视听体验，并验证导演工作流程。不能让自我表达盖过地方主体。
- 观众：暂按不熟悉南海子的公众理解，具体投放平台和核心受众未确认；当前概念修订可先进行。
- 预期结果：观众记住南海子及至少一个准确、具体、有意义的地方事实，并形成进一步了解的理由。实际效果未测。
- 可用事实：麋鹿回归与后续保护、迁地建群和野化放归；相关事实须回到研究记录核对，不能写成全球灭绝后复活。两块碑是已有纪念设计，不冒充原创。
- 制作边界：当前不安排实拍，考虑数字影像、动画或 AI 辅助；比赛规格见原赛事阅读记录。不得将工具提示词当成完成素材。
- 现有两案：《复原成功》的 AI 自省需让位于地方作用；《借景》的历史处境需要重新审视与地方传播目的的关系。均未选定，也未通过预览验证。
- 下一次提案必须交付：修改后的具体事件与结尾、观众能记住的地方内容、保留/改变理由及最小预览测试。禁止仅追加景点蒙太奇充当修复。

## 目前缺口及处理责任

1. 助手自行补：公开事实与来源核查、具体方案和详细镜头、工具可行性测试、版本记录。
2. 后续由用户判断：候选方向的表达取舍、对具体预览的反馈；不要求现在给出完整审美画像。
3. 制作前落实：素材使用条件、实际可用工具/预算、比赛最新完整要求与报名附件。能公开取得的先自行找，不能确认的注明。
4. 尚不能替代：真实观看反馈与完整作品制作证据。流程文字校验只能证明文件完整。
