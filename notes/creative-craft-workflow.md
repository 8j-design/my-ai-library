## 开始任务

在本资料库项目中告诉 AI：

> 先读 AGENTS.md 和 START_HERE.md，从技能入口打开 creative-craft 正文；INDEX.md 只列外部 GitHub 项目。我提供的主题是【主题】，目标是【目标】，受众是【受众】，必须包含【内容】，希望得到【构思/实际作品和格式】。按技能完成任务，并记录实际产物、检查结果和未完成项。

也可以只给一个主题；AI 应使用明确的暂定假设先推进，不因没有参考图停住。如果只要想法，完成构思；如果要求作品，应继续制作真实可查看的文件。

## 每个实际项目保留什么

以 `projects/项目名/` 为建议位置，简单任务可将前三项合并成一篇记录，已有项目结构时沿用原结构：

| 记录 | 应包含 |
| --- | --- |
| brief.md | 用户目标、受众、必须内容、媒介规格、事实与假设 |
| directions.md | 不同方向、推荐理由、用户选择或自主选择依据 |
| review.md | 修改原因、实际检查、限制、最终状态、后续事项 |
| outputs/ | 实际作品、预览及用户要求的可编辑文件 |

记录简明即可，不需要为了走流程生成空文件。不要保存不必要的个人信息或凭据。

## 验证与回写

完成作品后，打开文件检查关键文字、主题表达、资产、尺寸与媒介适用性；记录实际工具与版本（能取得时）、输出路径和通过/未通过项。没有看过实际作品不能宣称视觉验收通过。

新证据回写本流程或对应项目的状态与复盘记录；本库没有 `cards/skill-creative-craft.md`，不得向该旧路径写入或伪造外部卡。检查实际修改与受影响引用，卡片变化时才重建并检查 INDEX，再做已授权的 Git 存档。首次完整任务成功也只证明该任务范围；不能推广为所有包装、印刷或广告场景均已验证。
